# ripsbybenji.com

The public coming-soon page for Benji's Rips, served by GitHub Pages from `main`.

- `index.html`: the page and the waitlist form.
- `privacy.html`: the website and waitlist privacy notice.
- `CNAME`: the custom domain.

The source of truth is `website/coming-soon/` in BenjaminOne/rips-by-benjamin; copy changes from there. Waitlist sign-ups go to a company Google Sheet through the Apps Script in `website/waitlist/Code.gs` of that repo.
